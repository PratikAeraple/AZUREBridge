AZUREBRIDGE

Hybrid Cloud Infrastructure Platform

Architecture boundaries

BruteHost / private lab → IPsec site-to-site VPN gateway → Azure hub VNet → workload subnet and private services. Bastion or point-to-site access is an alternate operator path, not a public RDP/SSH rule.

Operational principle

The repository contains Terraform for a private Linux workload network, NSG rules, managed identity, monitoring and optional resources. No subscription ID, credentials, Terraform state or cloud resource is included.

Status at publication

Terraform architecture: IMPLEMENTED · Local formatting/validation: LAB VALIDATED · Azure deployment: REQUIRES EXTERNAL PLATFORM

What is not claimed

No Azure subscription was accessed and no cloud resources were created. Validation is local; plan/apply requires an owner-selected subscription and explicit cost review.

Implementation notes

  • Exact hostname and project identity are checked by the portal server.
  • HTTP requests redirect to HTTPS; HSTS is host-only with a conservative one-week max-age.
  • Content Security Policy permits only local assets; no third-party analytics or font origin is required.
  • Docker images use a pinned Node base, non-root runtime, read-only filesystem and no published port.
